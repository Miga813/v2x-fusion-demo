# 面向遮挡交叉口的车路协同感知融合 Demo

本项目构建了一个可复现的车路协同目标级融合仿真，用于验证遮挡交叉口场景下路侧感知补盲和通信退化保护方法。

项目支持车端遮挡、路侧通信时延、随机丢包、目标关联、时间补偿、卡尔曼状态估计，以及固定权重与自适应权重消融对比。Streamlit 页面可用于算法调试和线上面试共享屏幕展示。

## 主要功能

- 统一目标消息结构：
  - 目标 ID
  - 类别
  - 位置
  - 速度
  - 置信度
  - 协方差
  - 数据来源
  - 时间戳
- 二维常速度卡尔曼滤波
- 路侧历史消息时间补偿
- 类别和空间门限粗筛选
- 匈牙利算法一对一目标关联
- 车端遮挡和短时漏检模拟
- 路侧通信时延 `0–500 ms` 可调
- 路侧丢包率 `0–30%` 可调
- 固定权重与自适应权重消融
- 固定随机种子，可重复实验
- Streamlit 逐帧交互回放

## 算法流程

```text
车端检测 ─┐
          ├─ 坐标统一与时间补偿
路侧检测 ─┘
              ↓
       类别与空间门限筛选
              ↓
         匈牙利目标关联
              ↓
       固定或自适应权重融合
              ↓
         卡尔曼状态更新
              ↓
      融合轨迹与风险模块接口
```

## 自适应权重

传感器质量综合考虑：

- 检测置信度；
- 目标距离；
- 通信时延；
- 丢包率；
- 状态协方差。

通信质量下降时，路侧信息权重自动降低。固定权重模式用于消融实验。

需要注意，自适应降权的目标是增强退化通信条件下的稳健性，不保证在每个随机种子和每组参数下都严格取得最低 RMSE。

```powershell

```

```powershell
python -m pytest -q
```


### 4. 启动可视化界面

```powershell
python -m streamlit run app.py
```

```text
http://localhost:8501
```

## 默认实验结果

固定随机种子为 `42`，设置如下：

```text
通信时延：300 ms
丢包率：10%
启用车端遮挡
启用自适应权重
```

当前离线仿真结果为：

| 指标 | 结果 |
|---|---:|
| 单车位置 RMSE | 0.1282 m |
| 融合位置 RMSE | 0.0791 m |
| 相对改善 | 38.27% |
| 车端漏检率 | 18.18% |
| 路侧接收率 | 87.60% |

结果由仿真程序实时计算，没有在界面中硬编码。


## 与CARLA对接

当前版本是独立离线仿真，不依赖 CARLA。

后续接入 CARLA 时，可保留以下模块：

- `Detection` 统一目标消息；
- 卡尔曼预测与更新；
- 目标关联；
- 自适应权重融合；
- Streamlit 评价界面。

需要将 `simulation.py` 中的合成检测替换为：

- 车端传感器或感知模型输出；
- 路侧传感器输出；
- CARLA Actor 世界坐标真值；
- V2X 通信模块产生的时延和丢包状态。

如果传感器输出位于局部坐标系，还需要根据外参完成坐标变换。
